# Sampatakumar's Portfolio

> **Live portfolio:** [sampatakumar.github.io](https://sampatakumar.github.io/)

A personal portfolio built with React, TypeScript, Vite, and Tailwind CSS. It showcases my projects, technical skills, and blog content through a responsive interface with dark and light themes, interactive UI details, and a project gallery.

## Portfolio highlights

- Responsive portfolio, projects, and blog pages
- Theme-aware animated background and dark/light mode toggle
- Interactive project gallery with filters and detail views
- Developer-focused UI effects, custom cursor, and profile card
- Blog management dashboard backed by a Node.js server
